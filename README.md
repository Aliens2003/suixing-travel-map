# 随行 · 旅行地图

面向 iPhone 和 iPad 的个人旅行规划 PWA，可从 Safari 添加到主屏幕独立打开。进入网站先使用普通地图，通过「收藏夹」管理每次旅行的地点和路线。

## 功能与用法

1. 首页为铺满屏幕的地图，设置缩到搜索框旁，收藏夹从底部进入。定位成功后显示持续更新的蓝点；拖动地图后不自动拉回，点击定位才重新居中。后台暂停定位与方向监听。
2. 进入「杭州」「常州」等收藏夹后直接显示地图，底部是「标记位置／路线规划／地点列表」三个入口。标记菜单支持搜索、拖动地图用中心准星选点、从其他收藏夹添加；长按添加仍可使用。列表按需展开半屏面板，点选后收起并显示地点信息条，再按需详情或编辑。
3. 标记名称初始为搜索到的地名，可以自由修改。26 px 图标下方显示名称；长名称省略，重叠名称避让，选中地点优先显示。
4. 自定义分类、图标、颜色、关键词、备注、网址及想去／已去状态。
5. 同一地点可收藏到多个夹，名称和备注共享。从一个夹移除只清理该夹的路线；最后一个引用移除后清理该地点。
6. 点击「路线规划」展开半屏面板，每个收藏夹可建多条路线，日期可留空。手动添加地点、排列顺序，逐段选择步行、骑行、驾车或公交／地铁，点击后计算距离、时间和路段指引。收起面板保留路线；清除显示仅清理页面结果，切换收藏夹也会清除显示，保存的规划继续保留。
7. 独立账号密码登录，30 天会话与恢复码找回；无短信登录、不开放公众注册。修改先保存在本机，联网时同步；不同内容自动合并，同一字段或删除／编辑冲突由用户选择。支持 JSON 备份与恢复。离线可创建收藏夹、编辑已保存地点和调整路线顺序；此前计算的结果注明时间，不作实时路况。
8. Safari 分享菜单可添加到主屏幕。应用壳、Leaflet 与业务数据分别保存；地图瓦片不离线下载，搜索、地图选点和新路线计算需要联网。安全更新入口位于设置，有待同步或保存异常时不允许立即更新。

定位按钮同时尝试启用手机顶部朝向：支持且获得授权时显示蓝色箭头；未授权、设备不支持、精度不足或数据过期时仅显示蓝点。不用 GPS 行进方向冒充手机朝向。部分 iPhone 浏览器需点击定位按钮并允许运动与方向权限。地图固定北朝上，位置和方向不写入行程数据库或备份。

点选搜索结果先显示临时标记和紧凑信息条，收藏夹内点击添加后才编辑。保存后换成分类标记，取消编辑保留临时标记；替换结果或清除搜索会移除临时标记。收藏夹改名、删除仍可从名称旁的更多按钮进入。

## 数据版本

当前 `schemaVersion: 2` 使用 `folders`。独立 PWA 使用新的账号和数据库；从旧站导出 v2 JSON，再在新账号设置内导入，收藏夹、分类、地点与路线整体保留。导入为整份替换，先备份再操作。旧站保留原部署，两个站点不会自动互相同步。早期 v1 实验数据的重置逻辑仅属于旧 Sites 路径，不用于新站 v2 导入。

## 独立 PWA 部署

使用 Cloudflare Worker + D1 + Static Assets，配置模板为 `wrangler.pwa.jsonc`；`standalone/` 为独立入口，不信任任何 OAI 身份头。`vite.pwa.config.ts` 只构建静态 React 前端，运行时 API 由独立 Worker 处理。

需要 Node 24。安装依赖后：

```sh
npm run pwa:build
node scripts/check-auth.mjs
node scripts/check-standalone.mjs
node scripts/check-offline-sync.mjs
node scripts/check-pwa.mjs
```

隔离验收可运行 `node scripts/preview-pwa.mjs`，它只生成内存中的临时账号与数据；终端显示本地地址，输入 offline／online 可模拟服务器断开和恢复。不要使用它存放真实行程。

部署者先用官方 Wrangler 登录，再运行 `node scripts/deploy-pwa.mjs prepare` 创建专用数据库与迁移配置；生产配置保存在忽略目录 `.sites-runtime/`。首次可用 `bootstrap` 部署关闭初始化的壳，再以 Worker Secret 配置三个 AMAP 键。发布前检查 Worker 计划、额度及实际登录性能；免费额度不是无限使用保证，不能降低密码哈希强度适配额度。

首次账号创建运行 `npm run pwa:owner`，终端只显示无凭据的本机入口。本人在该入口跳转后的网页设置密码并保存恢复码；初始化凭据自动删除，10 分钟超时也会清理。已创建账号时不重新初始化。所有密钥通过官方 CLI 的 stdin 或控制台配置，不写源码。独立站配置不填入公开的数据库 ID 或账号信息。

## 原 Sites 版本的技术与本地运行

React、TypeScript、Vinext／Vite、Cloudflare Workers／D1、Zod、Drizzle、Lucide。已配置高德 JS API 和 Web 服务时使用高德底图、搜索与道路路线；未配置时为 Leaflet／OpenStreetMap 底图分支。

```sh
npm ci
npm run dev
```

启动地址以终端为准。线上由托管平台提供身份，本地开发使用模板模拟登录。D1 初始化需要将 `drizzle/` 内 SQL 迁移按顺序应用到本地数据库。现有后端依赖不能直接运行在 GitHub Pages。

| 环境变量 | 用途 |
|---|---|
| AMAP_JS_KEY | Web 端 JS API Key |
| AMAP_SECURITY_CODE | JS API 安全密钥，仅服务端 |
| AMAP_WEB_KEY | Web 服务 Key，仅服务端 |

实际密钥通过秘密环境变量或未跟踪的本地配置提供，不能放进源码和备份。内部坐标为 WGS84，高德服务边界转换 GCJ02。网站不主动收集定位历史，最近视野只保存在本机；查询「从当前位置前往」时使用当前位置请求路线。

## 原 Sites 检查与通用边界

```sh
npx tsc --noEmit
npm run build
node scripts/check-folders.mjs
node scripts/check-device-location.mjs
node scripts/check-travel.mjs
```

测试脚本需支持直接读取 TypeScript 的 Node.js 版本（如 Node 24）；接口测试仅运行于启动后的本地 5173 服务，会暂存并恢复本地状态。覆盖共享地点、收藏夹与路线独立性、名称避让、身份、请求来源、版本冲突、无效数据拒绝，以及定位暂停恢复、权限拒绝与重试、过期回调取消、朝向可信度和资源清理。传感器测试使用模拟接口，不代替实体手机的硬件验收。

实体 iPhone／iPad 定位授权、触摸操作、双设备与断网恢复需要实机验收。路线只作规划，不自动安排时间；实时导航可跳转高德。没有离线地图下载、手绘路线或自动购买服务。浏览器本机存储可能被系统回收或被手动清除，未上传的修改不等于云端备份，旅行前应确认已同步并导出 JSON。同账号多开页面时只有一个页面取得写入锁，其他页面只读，避免覆盖离线内容；关闭占用页面后可重试。

仓库不包含个人行程、实际密钥、开发报告、本地数据库、缓存或依赖安装目录。第三方许可证保留在相应文件中。
