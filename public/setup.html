SUIXING / CONNECT YOUR MAP

让地图连接真实的旅途。

收藏、分类、旅行和账号同步独立运行。接入高德后，才能在随行内搜索地点和查询步行、骑行、驾车、公交路线。

1. 创建你自己的开发者应用

前往高德开放平台控制台，按官方要求注册、认证、确认适用条款。为“随行”创建应用。

服务可能有免费配额和超额费用。先核对控制台权益、限制与计费规则，不购买或开通付费套餐。

2. 创建两类 Key

Web 端（JS API）：用于底图显示；同时取得对应的安全密钥。将本站正式域名配置到允许使用的域名中。

Web 服务：用于服务端地点搜索和路线查询。按控制台要求设置安全限制。

网址：

3. 配置到网站运行环境

让开发助手通过 Sites 的环境变量工具配置以下名称，然后重新部署：

AMAP_JS_KEY：Web 端 Key
AMAP_SECURITY_CODE：JS API 安全密钥
AMAP_WEB_KEY：Web 服务 Key

安全密钥和 Web 服务 Key 应配置为服务端秘密，不放进源码、公开页面或备份。不要把秘密密钥发在公开聊天中。

4. 做一次真实验证

刷新页面，确认显示高德底图；搜索一个熟悉的地点，再查询一段步行、骑行、驾车和公交路线。核对位置、距离、时间和服务配额。未完成真实验证前，不将路线结果视为已验收。
